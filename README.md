# Keeping Contact

[![Project Page](https://img.shields.io/badge/Project-Page-blue)](https://keeping-contact.github.io/)
![arXiv pending](https://img.shields.io/badge/arXiv-Link%20pending-lightgrey)

This repository contains the research project website for *Keeping Contact: Task-Adaptive Friction Margins for Bimanual Non-Prehensile Manipulation*. The page illustrates task-adaptive friction margins in contact force planning and presents representative real robot bimanual tilting experiments.
